PORTOFOLIO FILDA DWI MEIRINA — HTML, CSS, JAVASCRIPT

CARA MENJALANKAN DI XAMPP (WINDOWS)
1. Ekstrak folder alfina-portfolio.
2. Salin folder tersebut ke C:\xampp\htdocs\
   Jika ingin menggunakan lokasi yang sudah disebutkan, pastikan file-file berada di:
   C:\xampp\htdocs\alfina-portfolio\index.html
3. Buka XAMPP Control Panel. Jalankan Apache.
4. Buka browser dan kunjungi:
   http://localhost/alfina-portfolio/

FILE
- index.html : struktur dan konten halaman
- style.css  : desain, warna, layout, dan responsivitas
- script.js  : menu mobile, filter proyek, animasi, tahun otomatis, tombol kembali ke atas

SEBELUM DIPUBLIKASIKAN
- Periksa email pada tombol kontak (filda.meirina@gmail.com) dan ganti bila bukan alamat yang ingin digunakan.
- Ganti link GitHub yang masih mengarah ke profil umum menjadi URL repositori masing-masing proyek.
- Tambahkan foto profil, gambar dashboard, dan tautan sertifikat asli jika ingin.
- Periksa kembali detail proyek, tanggal, dan pengalaman agar sesuai dengan data final.

Catatan: Google Fonts dan ikon Lucide membutuhkan koneksi internet. Website tetap dapat dibuka lokal; jika ingin sepenuhnya offline, unduh aset font dan ikon lalu ubah referensinya.
